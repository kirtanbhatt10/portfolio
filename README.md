# Portfolio

**Personal site of Kirtan Bhatt: projects, hackathon results, skills and contact.**

**Live:** <https://kirtanbhatt10.github.io/portfolio/>

## What is on it

- **Work:** a page each for Sentinel AI, Zenny AI Therapist, Sugam, Solaris and the AI Code Security Platform.
- **Lab:** a working terminal, a live SHA-256 hasher and a password entropy meter.
- **About and contact:** education, leadership, recognition and how to reach me.
- **Command menu:** press `/` or `Ctrl`/`⌘` + `K` to jump anywhere from the keyboard.

## Built with

Plain HTML, CSS and JavaScript, with no framework and no build step. Hosted on GitHub Pages.

## Run it locally

```bash
git clone https://github.com/kirtanbhatt10/portfolio.git
cd portfolio
python -m http.server 8080         # then open http://localhost:8080
```
